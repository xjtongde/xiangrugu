# 五件文本源侧规范值期望证据

开发验证产物，不是冻结合同、导入证书或数据库验收。实施授权、RED/GREEN、环境与失败裁定见[执行账](../../plans/2026-10-08-text-source-values-progress.md)。

本目录保存新增源侧非执行期望、探针日志及合成/镜像验证日志，不覆盖原release。真实读取仅五件已批准文本及已验收项目快照证书；原NAS/数据库均未访问。对所选五件做前后摘要核验，不称本次全快照验证。

期望采用XRGVALUE-v1：不含头部，所有源列为text且不可为NULL（空串保留），最后为1起始bigint行号。CSV独立字段解析与手写帧参考同时检查；不是用旧库生成答案，也不把双方摘要相等当数据库逐值验收。

artifact-hashes.json记录16份回传证据的SHA-256及32原位置；final-boundaries.log另核对包内脚本/模块与同步源码一致、长期容器/旧标签未变。失败日志保留，不据其前缀输出宣称成功。
