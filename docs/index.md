# index.md —— 香如故项目文档索引

> **定位（2026-09-22 用户指令"index.md 所有文档的索引"）**：全部文档的注册表与本文件体系权威顺序的唯一记载处。**新增/退役任何文档必须同批在本文件登记/除名**（R-06 账目闭环核查项之一）。

## 必读

### `AGENTS.md`

AI 助手入口。§1＝项目目标与核心思想（唯一记载处，**当前待用户定义**）；§3＝必读链。

### `rules.md`

**项目纪律总纲（元纪律，R-01～R-06）**：动手前须口令 / 需求挂账 / 三本专职账与归属判定 / 文档单一源 / 文档变动日志 / 每轮文档对齐核查（本轮才算收口）。做事方法条款以本文为唯一权威展开，他文一律指针。R-07 起为项目专属纪律预留条款位。

### `docs/index.md`（本文件）

文档索引＋权威优先级＋阅读顺序。

### `docs/codemap.md`

**代码地图与部署位置（一文两用，2026-09-22 用户指令开设）**：目录树、模块职责表、依赖关系的唯一展开处；运行环境与部署位置事实表。结构性变更须同轮刷新（R-06 核查覆盖）。

### `docs/log.md`

**文档变动日志（R-05）**：跟踪文档本身的结构性变动（开设/迁移/退役/修订批/对齐核查结论），新条目加最上面，日常逐条记账不回填。

## 三本专职账（R-03：bugs 装坏、improvements 装不对、features 装未有）

### `docs/bugs.md`

Bug 账本（B-编号）：缺陷唯一新增记账处。先记后修，修复须用户口令"修"（R-01）。

### `docs/improvements.md`

改进账本（I-编号）：不新增能力的"现状不对"记账处。默认挂账，"启用"须口令（R-02）。

### `docs/features.md`

新增功能账本（F-编号）：新能力/新来源需求记账处，条目含标尺归属字段（项目标尺定型前记 `待判`）。默认挂账（R-02）。

## 存档

### `docs/notes.md`

**跨会话纪要存档账（N-编号，2026-09-22 开设）**：用户交录纪要的唯一照录存档处（不改写/不评注）；纪要内 ✅实测／⚠未实测／❌证伪 标注即权威结论。在册：N-01＝2026-09-22 历史数据资源盘点（NAS 数据、外部资源、证伪黑名单、方向备忘——后者已挂账 F-01～F-07）。

## 权威优先级

```text
1. 用户当前明确指令
2. AGENTS.md §1（项目目标与核心思想）
3. rules.md（做事方法纪律）
4. docs/codemap.md 与三本专职账
5. 其他文档（定型后陆续登记于此）
```

任何文档表述不得与此冲突；发现冲突：**停止猜测，明确指出冲突并报告用户**（联动 R-06：涉代码的矛盾只入账不改码）。

## 新会话阅读顺序

```text
AGENTS.md → rules.md → docs/index.md → docs/codemap.md → 按需查三本账 → docs/notes.md（跨会话纪要与资源盘点）
```

## 变动记录约定

本索引自身的结构变动记入 `docs/log.md`；各文档职责一句话以本文件为准（R-04），文档自身开头定位块与其冲突时以本文件为准并记补正注。
