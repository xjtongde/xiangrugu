## 二、制式差异（最易误判处）

本地件把**清代縉紳錄**料**归并成任期区间**（一人一职一段任期＝1 行），官方 Access 件是**逐年名录**（一人一职一年＝1 行）：

| 指标 | 本地 0919 件 | 官方 2025-05 件 |
|---|---|---|
| `POSTED_TO_OFFICE_DATA` 行 | 591,518 | 1,979,566 |
| 　`c_posting_id` 去重 | **591,487** | 1,979,530 |
| `POSTED_TO_ADDR_DATA` 行 | 465,284 | 1,853,262 |
| 　`c_posting_id` 去重 | **464,682** | 1,852,415 |
| **每任职地点链接数** | **1.000** | **1.000** |

⇒ **两制式不可按行数互校**；与官方口径对账必须先做制式换算。**地点信息不丢**（蘇軾 `c_personid=3767`：官方 36 条地点记录＝18 个不同地点，本件 34 条＝同样 **18** 个）。
成因：该批料 `TEXT_CODES.c_textid=67147`《清代量化数据库(縉紳錄)》2024-08 入档，官方件 1,581,438 行＝其仕历表之 79.9%；实例 陳國贊（`669624`，清）官方 **318 行**同一官职（司獄）逐年各一行，本件**归为 1 行**（司獄，1864–1909）。

## 四、使用边界一句话

本件是**结构完整、内容在长、但索引尽失、占位符无官方解释、坐标仅半覆盖、事件与社会关系层近乎沉默**的快车道件：
**做人物/任职/亲缘统计可用**（须先处理 G4-01…G4-05 之占位符与哨兵）；**做 GIS 上图须显式处理无坐标与无 `CHGIS_PT_ID` 分支**（G4-06/G4-12）；**做纪年换算须避开两陷阱**（G4-13/G4-14）；**做事件与行迹不可依赖本件**（G4-11）；**做关系网络上图不可依赖本件**（G4-10）。
