# 正式请求读取器静态复核

独立复核限 `request_reader.py`、`task_control.py` 的接线和相关保护测试。复核者没有发现P0至P2问题。严格分支保持逐次请求重读、字节比较、挂载检查、取消和截止。快速路径先校验O_PATH描述符，再核对可读描述符的设备号和inode，保留文件类型及有界读检查。

P3涉及测试可见性。支持性用例可能在意外回退时跳过。最终验证将安装态该用例实际执行以及整批读取器回退调用数作为独立门槛。

复核未裁定定制Python、其他seccomp环境及并发路径或挂载替换的原子性。目标镜像自带ctypes，兼容回退面向无快速调用能力的标准环境。安装态、吞吐和真实源可行性分别需要运行证据。
