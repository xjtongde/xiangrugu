## §5 Dockerfile（审稿草案；权威副本在此，pg32-upgrade.md 存照不回改）

```dockerfile
# pg36-full —— PG18 ＋ PGDG 官方源全功能集（口径：只取官方源；钉大版本，扩展随 PGDG 浮动）
FROM postgres:18-bookworm

RUN apt-get update && apt-get install -y --no-install-recommends \
      postgresql-18-postgis-3 postgresql-18-postgis-3-scripts \
      postgresql-18-pgrouting postgresql-18-h3 postgresql-18-address-standardizer \
      postgresql-18-pgvector postgresql-18-rum postgresql-18-pg-ivm postgresql-18-hypopg \
      postgresql-18-cron postgresql-18-repack postgresql-18-partman postgresql-18-pgaudit \
      postgresql-18-wal2json postgresql-18-pg-stat-kcache \
      postgresql-18-mysql-fdw postgresql-plpython3-18 postgresql-18-pgtap \
      postgresql-18-pglogical postgresql-18-decoderbufs \
   && rm -rf /var/lib/apt/lists/*
```

注：`pointcloud` 不装（本项目无点云用途）；`pgdg.list` 基础镜像自带（pg32 容器内实测在位）；体积预估基座 629MB→约 1.2GB（build 时实测）。

## §6 docker-compose.yml（审稿草案）

```yaml
services:
  postgres:
    image: pg36-full:18-pgdg
    build: .                      # 与 image 同置：compose build 产出即该 tag
    container_name: pg36
    restart: unless-stopped
    ports:
      - "5432:5432"
    environment:
      - TZ=Asia/Shanghai
    env_file: .env
    volumes:
      - ./data/postgres:/var/lib/postgresql
      - /etc/localtime:/etc/localtime:ro
      - /etc/timezone:/etc/timezone:ro
    command: >-
      postgres
      -c shared_preload_libraries=pg_stat_statements
      -c shared_buffers=1GB
      -c work_mem=16MB
      -c maintenance_work_mem=256MB
      -c effective_cache_size=4GB
    shm_size: 128mb
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U $${POSTGRES_USER} -d $${POSTGRES_DB}"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 30s
    logging:
      driver: "json-file"
      options:
        max-size: "50m"
        max-file: "5"
```

1. **扩展版本不钉死**（随 PGDG 浮动）vs 标准 §12.3"锁定小版本"：标准原文对象是**镜像 tag**（禁 latest），基座已钉 `18-bookworm`；扩展若钉死，PGDG 清旧版会致日后 build 失败。**折衷**：build 时 `apt` 解析版本全量回填 README"版本记录"＋镜像 label，保证可追溯。
2. **自建镜像**：标准未禁（36 已有 voicebox 自建先例）；Dockerfile 存项目目录可复建，README 写明基座与包清单。
3. **`command:` 注入调参与 preload**（偏离镜像默认 CMD）：按 §0.4 精神在方案（§4/§6）显式标注；preload 面最小（仅 pg_stat_statements）。
4. **shm_size 128mb**：官方镜像要求＋标准 §0 已实例（32 部署）同款；将来并行大分析如需调大，另行变更并登记。
