# PITFALLS.md —— 导入防坑清单

> 状态：现行｜as_of 2026-10-06

每条都必须由设计约束或自动测试拦截。历史细节可从 Git 查看；本文件只保留对当前实现有约束力的结论。

| 编号 | 失败模式 | 当前规则与必测拦截 |
|---|---|---|
| P-01 | 用被测系统产生验收基线 | 期望值由独立源读取器生成；注入共同错误时验证必须失败 |
| P-02 | 行数或指纹代替值全等 | 正式验收逐行逐列比较；修改一个值必须被检出 |
| P-03 | 叙述日志被当作证明 | 只接受结构化结果和每表证书；缺证书即不放行 |
| P-04 | 把抽样观察推广到全量 | 抽样只用于开发反馈；正式闸门必须覆盖合同全集 |
| P-05 | 让 GDAL 自动猜文本编码 | 列级编码必须在 `decoding.yaml` 声明并有证据；错码用例必须失败 |
| P-06 | 把文件级编码强加给混合编码列 | 编码粒度至少到文本列；混合列夹具须逐列正确还原 |
| P-07 | GBK 解码吞掉孤立高位字节 | 非法字节策略必须显式、可逆追踪；坏字节位置必须进入证书 |
| P-08 | 用 SQL 反向转码修复乱码 | 禁止装后猜测修复；原字节、解码配置和库值须能三方核对 |
| P-09 | `-append` 静默丢弃不匹配列 | 禁止依赖隐式 append；列集合不完全匹配时必须中止 |
| P-10 | XLS/XLSX 表头被当成数据 | 每 sheet 显式声明表头/跳行；夹具验证首行和值计数 |
| P-11 | 单后缀匹配漏掉 `.zip.zip` | 容器递归按成员签名/链展开；多层和大小写后缀均有测试 |
| P-12 | 工作账 append 在 `/tmp` | 工作账写模块运行区，使用运行 ID 和唯一键；中断重跑不得重复 |
| P-13 | 推测或转换源 CRS | 保留源声明与坐标，不自动重投影；缺失/非标准 CRS 明确阻塞或原样登记 |
| P-14 | 用 `UPDATE` 掩盖导入错误 | 保真层从源重装；故障注入证明补丁路径不存在 |
| P-15 | 栅格参数未入证据 | 尺寸、波段、类型、NoData、仿射和 CRS 等进入证书并逐项比较 |
| P-16 | 重建资产未版本化 | 配置、代码、合同和证书模式均入 Git；环境外唯一副本视为失败 |
| P-17 | 硬编码绝对路径 | 根只从 `roots.yaml` 读取；静态检查拦截已禁路径和业务代码绝对路径 |
| P-18 | 无编排器，靠不可重入修复链 | 单一 CLI、显式状态机；中断后重跑测试必须幂等 |
| P-19 | 未验证可重建就删库/备份 | 删除任何库前须独立重建成功、证书通过并获用户单独授权 |
| P-20 | 数字没有时点、范围和分母 | 所有计数带对象集合、口径、as_of 与生成方式 |
| P-21 | 与错误上游或旧库比较 | 唯一验收基线是 `usedata`；旧 `cbdb` 只观察 |
| P-22 | 把源问题和我方缺陷混记 | 先比较源与目标；相同则按 R-07 记录源生事实，不进入导入修复队列 |
| P-23 | 未知哨兵值被擅自解释 | 忠实保留未知语义值；只有来源证明后才增加语义说明 |
| P-24 | 本地超时留下远端孤儿进程 | 任务须有远端运行 ID、进程组、取消与回收；超时测试检查无残留 |
| P-25 | 字节数被报告为字符数 | 指标明确单位并由对应 API 计算；多字节文本用例校验字符/字节差异 |
| P-26 | 校验账有效记录通过便忽略格式垃圾 | 校验账先锁原始摘要并严格解析；NUL、坏行、重复项和越界路径全部入证据，兼容解析只允许冻结合同绑定精确摘要 |

实现评审时逐条回答“由哪段代码、哪项配置、哪个测试拦截”；没有答案的条目就是未完成，不得以“操作时注意”代替。
